Fynix is a **fast, flexible, and extensible PHP validation engine** built for applications that need to validate primitives, files, DTOs, nested object graphs, and arrays without sacrificing clarity or type safety.

## Why teams choose Fynix

- immutable, chainable rules for predictable validation logic
- validator families for strings, numbers, files, uploads, enums, and objects
- nested object and object-array validation through `ValidationRegistry`
- structured `ValidationError` payloads for JSON APIs, plus flattened strings for forms
- zero public constructor-based validation API in v3

## Core workflow

```php
use Fynix\RuleSet;
use Fynix\ValidationHandler;
use Fynix\ValidationRegistry;

final class User
{
    public string $firstName = '';
    public string $email = '';
}

ValidationRegistry::register(
    User::class,
    static fn (RuleSet $rules): array => [
        $rules->string('firstName')->min(2)->max(50),
        $rules->email('email')->max(180),
    ]
);

$errors = ValidationHandler::validate(new User());
```
